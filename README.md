# Exp - 5 STUDENT ENROLLMENT SYSTEM

# AIM:
To study the problem statement and Software Requirements Specification (SRS) of a Student Enrollment System and design the required UML diagrams to represent the system.
# SRS (Procedure):
Step 1: Problem Identification

The main problem is to develop an automated system that allows students to enroll in courses easily and efficiently.

Step 2: Requirement Analysis

Identify the users involved in the system:

Student Admin Payment Gateway Course Coordinator

Define functional requirements such as:

Student registration and login View available courses Select and enroll in courses Check course details Make fee payments Confirm enrollment Admin manages students and courses Course coordinator manages course information Step 3: System Design

Design the Student Enrollment System using UML diagrams:

Use Case Diagram Class Diagram Activity Diagram Sequence Diagram Communication Diagram Package Diagram Step 4: System Interaction

Represent the interaction between the Student, Admin, Payment Gateway, and Course Coordinator and the enrollment system.
